# Agent Instructions

This file gives AI coding agents the context they need to work in this repo.

## Agent skills

### Issue tracker

Issues live in GitHub Issues (`github.com:OfficerYoda/basf-hackathon`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-label vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
